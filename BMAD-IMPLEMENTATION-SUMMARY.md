## 💡 How It Works

### The BMAD Cycle

```
1. READ Documentation
   └─ .instructions.md (architecture)
   └─ CONTEXT.md (technical)
   └─ PHASES.md (plan)

2. IDENTIFY Your Role
   └─ AGENTS.md (responsibilities)
   └─ SKILLS.md (expertise areas)

3. ASK AI for Help
   └─ Use .prompt.md patterns
   └─ Invoke skills by name
   └─ Reference documentation

4. GET Specific Help
   └─ AI reads your context
   └─ Provides targeted guidance
   └─ Accelerates your work

5. TRACK Progress
   └─ PHASES.md milestones
   └─ Success criteria
   └─ Team updates
```

### Example Workflow

**Scenario: Implement Tier-2 Graph Query**

```
@architect: Design the Tier-2 query
  Reference: CONTEXT.md database schema
  Requirements: file-level call graphs
  Output: query template + indexes
  ↓
@backend-dev: Implement using neo4j-queries skill
  Template from: architect's response
  Skill location: skills/neo4j-queries/SKILL.md
  Output: working endpoint
  ↓
@qa-engineer: Design tests using test-strategy skill
  Skill location: skills/test-strategy/SKILL.md
  Output: test cases + 90% coverage
  ↓
@architect: Optimize for performance
  Target: <1 second (from CONTEXT.md)
  Skill: performance-optimization/SKILL.md
  Output: optimization recommendations
```
